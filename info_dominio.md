# Informações do Domínio - Nutra3

**Domínio Principal Registrado:** `officialbodycare.shop`
**Estratégia:** Foco em saúde, cuidados corporais e bem-estar (Body Care).
**Uso:** Todos os projetos (subpastas) dentro do diretório `Nutra3` estarão hospedados e associados a este domínio.
**Repositório GitHub:** `https://github.com/Uildigital/Nutra3.git`

## Regras de URL para Campanhas (Google Ads)
Ao criar novos geradores de campanha (`campanha_nomedoproduto.html`) para produtos dentro do Nutra3, utilizar o domínio base:
`https://officialbodycare.shop/[NOME_DO_PRODUTO]?utm_id={campaignid}&utm_source=google&utm_medium={adgroupid}&utm_campaign=nomeCampanha&utm_term={keyword}&utm_content={creative}&network={network}&device={device}&ftgid=ftgid_{gclid}_ftgid`

*(Esta página de anotações garante que a IA sempre utilize a URL correta ao criar novas estruturas para a pasta Nutra3).*
